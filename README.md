# Run The Day — Homepage

Premium sports-editorial marketing homepage for [Run The Day](https://www.runtheday.com/).

## Preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deliverable

- **`index.html`** — single self-contained page with inlined CSS and JavaScript
- **`assets/`** — brand fonts, images, and icons referenced by the page

Brand identity preserved: black / gold / teal, Proxima Nova, RTD logo.
