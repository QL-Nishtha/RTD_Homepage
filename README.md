# Run The Day — Homepage

Premium sports-editorial marketing homepage for [Run The Day](https://www.runtheday.com/).

## Preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deliverable

- **`index.html`** — single self-contained page (inlined CSS + JS) using the premium black / gold / teal design system
- **`assets/images/ref/`** — photographs and partner logos extracted from the summer26 reference
- **`run-the-day-new_home summer26.html`** — full source-of-truth reference file

Content (metrics, pricing, case studies, form fields, markets, story) is taken from the summer26 reference.
